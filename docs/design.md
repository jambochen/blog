# 網站視覺風格

最後更新：2026-10-14

這份文件記錄網站目前的外觀與它的理由，給修改版面、元件或新增頁面的人（包含 coding agent）對照。文章的寫作風格見 [style.md](style.md)，背景動效的生成方式見 [terrain-wallpaper.md](terrain-wallpaper.md)。

## 概觀

頁面是白紙黑墨的排版：方角、沒有陰影，以粗細不同的線分隔內容。標題用特粗的明體，內文用黑體，數字用窄體的拉丁字。顏色只用在三個地方：連結、琥珀色的標記、以及每個系列自己的色調。紙面後方有一層很淡的畫布動效。

深色模式沿用同一套版面，只換顏色。

## 顏色

顏色都定義在 `src/styles/global.css` 的 `:root`，元件一律以變數取用。

| 變數 | 淺色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#fff` | `#15181c` | 頁面底色 |
| `--surface` | `#e1e5e9` | `#1f2429` | 行內 code、code 區塊、摺疊大綱的底 |
| `--ink` | `#16191d` | `#dde1e6` | 內文、標題、粗線 |
| `--muted` | `#59616b` | `#8d96a0` | 日期、說明、大綱、引言 |
| `--rule` | `#c6ccd3` | `#2e353c` | 細分隔線，圖裡的細線也用它 |
| `--accent` | `#2a3a9c` | `#a3b0ff` | 連結，以及滑鼠經過時的標題 |
| `--amber` | `#eda900` | `#f5b41a` | 標記，見下 |

琥珀色只當標記，不當文字顏色：鍵盤焦點的外框、選取的文字、主選單目前頁面的底線、跳到某一節時標題閃過的底色、搜尋結果裡符合的字。背景掃描線的琥珀色另外寫在 `src/lib/wallpapers/terrain.ts`。

code 區塊的底色寫在 `astro.config.mjs` 的 Expressive Code 設定裡，數值與 `--surface` 相同；改 `--surface` 時兩處一起改。

### 系列的色調

每個系列在 `src/content/series.json` 選一個色調（tone），由 `[data-tone]` 套到首頁的系列區塊與該系列文章的頁首。色調同時改寫 `--accent`，所以一篇文章裡的連結顏色跟著系列走。

| 色調 | 色塊 | 淺色連結 | 深色連結 |
| --- | --- | --- | --- |
| `page` | 不填色 | `#b8400a` | `#ff8f45` |
| `indigo` | `#2a3a9c` | `#2a3a9c` | `#a3b0ff` |
| `vermilion` | `#cf3a1b` | `#b8300f` | `#ff9478` |
| `moss` | `#4d6a2c` | `#44601f` | `#b1cf86` |

- `page` 不填色，區塊上下各一條 0.3rem 的粗線，背景動效可以透出來。目前兩個系列都用它。
- 填色的色塊在深淺兩個主題是同一個顏色，上面的字固定為白色（`--block-ink`），不跟著頁面變。
- 色塊的顏色在深色頁面上當文字太暗，所以深色主題的連結各用一個較亮的同色系。

### 不跟主題走的東西

系列文末的糰子與 404 頁的房間在兩個主題是同一個畫面，顏色寫死在各自的元件裡。

## 字體

四個字體在 `astro.config.mjs` 的 `fonts` 設定，以 CSS 變數取用。

| 變數 | 字體 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--font-mincho` | Noto Serif TC | 400、700、900 | 標題、系列名、主選單、文章標題列、表頭 |
| `--font-gothic` | Noto Sans TC | 400、700 | 內文與說明 |
| `--font-ui` | Barlow Semi Condensed | 500、600 | 篇號、日期、年份、互動圖的標籤、畫布上的讀數 |
| `--font-code` | Commit Mono | 400、700 | code |

- 內文用黑體，因為明體的橫筆很細，在一般解析度的螢幕上以內文字級顯示會糊。
- 標題用 900 的明體。它沒有窄體，所以首頁的系列名與「關於」以 `scaleX(0.76)` 壓窄。
- 標題一律橫排。多數標題夾有英文（LLM、agent、prompt），直排不易閱讀。
- 兩個拉丁字體不帶通用的後備字體，因為它們在 `font-family` 裡排在中文字體之前，`serif` 會先被選中而吃掉所有中文字。

### 字級

根字級是 106.25%（17px），其餘字級取 1.25 的倍率：

| rem | 用在 |
| --- | --- |
| 7.451 | 文章頁首的篇號（寬螢幕） |
| 3.815 | 首頁的系列名、「關於」（寬螢幕） |
| 3.052 | 頁面的 h1、文章標題的上限 |
| 2.441 | 系列名（窄螢幕） |
| 1.563 | 內文 h2、列表的年份、系列區塊的篇號 |
| 1.25 | 內文 h3、列表裡的文章標題、站名 |
| 1 | 內文、內文 h4 |
| 0.75 到 0.9 | 說明、日期、大綱、表格、頁尾、圖裡的標籤 |

內文行高 1.85，標題 1.15 到 1.45。數字都開 `tabular-nums`，篇號補零成兩位。

## 版面

- `--column`（66rem）是內容最寬的範圍，`.wrap` 把內容置中在這個欄裡；背景動效避開這一欄。
- `--measure`（42rem）是內文的行寬，`.prose`、文章說明與搜尋結果都用它。
- `--gutter` 是欄與視窗邊緣的距離，`clamp(1.25rem, 5vw, 4rem)`。
- 內容一律靠左對齊。

形狀只有直角與直線：

- 圓角只出現在兩個畫出來的東西上：頭像與糰子。
- 陰影只出現在連結預覽的卡片，是不模糊的 4px 位移。
- 線有四種：1px 的 `--rule` 分隔列表的每一列，1px 的 `--ink` 在頁首下方，3px 用於引言的左邊與主選單的底線，0.3rem 的粗線框住一個不填色的區塊。

斷點：

| 寬度 | 變化 |
| --- | --- |
| 52rem 以上 | 系列區塊與關於頁分成左右兩欄；文章頁首的篇號移到標題左側 |
| 62rem 以上 | 關於頁的聯絡方式把說明排到同一列 |
| 75rem 以上 | 關於頁的雨中行走動畫固定在視窗右下角 |
| 1000px 以下 | 文章的大綱從右側移到內文上方，改成可摺疊 |
| 34rem 以下 | 文末「下一篇」的箭頭與標題改成上下排 |

## 頁面

- **頁首**（`Header.astro`）：站名、文章、關於、搜尋與深淺色切換，下方一條墨色細線。目前所在的頁面以琥珀色底線標出。
- **首頁**（`index.astro`）：每個系列一個區塊（`Shelf.astro`），左邊是壓窄的系列名與篇數，右邊每一列是篇號、標題與說明。滑鼠經過一列時該列反白。單篇文章集中在最後一個區塊，列出最新的八篇。
- **文章列表**（`posts.astro`）：先列系列，再依年份列出全部文章（`PostList.astro`）。
- **系列頁**（`[series].astro`）：系列名、說明、依閱讀順序排列的文章。
- **文章頁**（`BlogPost.astro`）：頁首是大篇號、系列名與第幾篇、標題、說明、日期；下方左邊是內文，右邊是跟著捲動的大綱，只展開目前所讀那一節的小節。系列文章的文末有一排糰子，每一顆是系列裡的一篇，目前這一篇會跳，未發佈的畫成虛線。最後是上一篇與下一篇；系列還有後續時，下一篇前面是「To Be Continued」的箭頭。
- **關於**（`about.astro`）：與首頁的系列區塊同一個形式，左邊是標題與頭像，右邊是自我介紹與聯絡方式。
- **搜尋**（`search.astro`）：一個輸入框與結果列表，索引由 Pagefind 在建置時產生。
- **404**（`404.astro`）：不用頁首與頁尾。灰色的房間裡有向遠處延伸的白線，紅底的「失去同步」與所輸入的網址。點「重新同步」時畫面加速並轉白，再回到首頁。
- **頁尾**（`Footer.astro`）：年份與站名，GitHub 與 RSS 的圖示。

- **分享圖**（`src/lib/shareCard.ts`）：連結貼到社群時顯示的 1200×630 圖片，建置時每篇文章產生一張，其餘頁面共用一張。版式取自文章頁首：上方一條粗線，左邊大篇號，右邊系列名與標題，左下是站名與琥珀色底線。固定用淺色主題的顏色。

圖示用 `astro-icon` 與 Material Design Icons 的套件，不手寫 SVG 路徑。

## 文章內的元件

- **code 區塊**：Expressive Code，主題是 vitesse-light 與 vitesse-dark，方角、無邊框、無陰影，標題列是墨色。
- **行內 code**：`--surface` 的底，字級 0.85em。
- **表格**：只有橫線，表頭下方是墨色線，表頭用明體。太寬時表格自己橫向捲動。
- **引言**：左邊一條 3px 的墨色線，文字用 `--muted`。
- **數學式**：MathJax 在建置時轉成 SVG；獨立的式子太寬時橫向捲動。
- **Mermaid 圖**：在瀏覽器裡繪製，顏色取自頁面的變數，切換主題時重畫。
- **靜態圖**（`Diagram.astro`）：以 diagram-design 畫成的 SVG 內嵌在文章裡。`src/lib/diagram.ts` 把圖裡的顏色換成頁面的變數，並把圓角方塊與有底色的分區改成方角與粗線。點圖可以放大。
- **互動圖**（`FigureFrame.astro` 與 `src/components/` 裡的各個圖）：圖裡的文字很少，標籤是簡短的英文，說明留給內文。數字靠右對齊並保留固定寬度，數值變動時位置不移動。一張圖以一個大數字作結。按鈕是方角的細框，按下時反白。
- **站內連結**：由 wikilink 產生的連結維持內文的顏色，只以底線標示，滑鼠經過才變成連結色，因為一段裡常有好幾個。滑鼠停在上面時顯示預覽卡片（`XrefPreview.astro`），列出所在的文章、節名與摘要。

## 動效

動效分成兩類。背景那一層自己會動，其餘都是回應讀者的操作。

- **背景**（`Wallpaper.astro`）：一般頁面是等高線地形與掃描線，文章頁是右下角的三體模擬。畫布在內容欄的範圍內調淡或隱藏，只有兩側空白是全濃度。細節見 [terrain-wallpaper.md](terrain-wallpaper.md)。
- **換頁**：以瀏覽器的 view transition 淡入淡出。文章標題與系列名在兩頁之間帶著同一個名稱，所以點一篇文章時，標題從列表移到文章頁首。頁首自成一層而保持不動。換頁當下不在視窗內的元素不參與移動。
- **跳到某一節**：標題閃過琥珀色的底，1.8 秒內褪去。
- **大綱**：目前所讀那一節的小節展開，其餘收起。
- **系列區塊的一列**：滑鼠經過時反白。
- **To Be Continued 的箭頭**：捲到它的位置時從右邊滑入。
- **糰子**：整排輕輕晃動，目前這一篇跳動。
- **404**：進入時上一頁褪色並模糊，離開時畫面轉白。

系統設定為減少動態時，以上全部停用，背景只畫一張靜止的畫面。

文章裡現有的互動圖與靜態圖不加進場動畫。

## 深色模式

主題記在 `<html>` 的 `data-theme`。`BaseHead.astro` 裡的一段行內腳本在第一次繪製之前設定它：先取 `localStorage` 裡的 `theme`，沒有時跟隨系統設定。頁首的按鈕切換並存下選擇。

切換時畫布場景重新建立，Mermaid 圖重畫，code 區塊由 `[data-theme]` 選擇器換主題。

## 檢查

改動版面，或新增圖、表格、code 區塊之後，以 375px 的寬度在深淺兩個主題各看一次：

```sh
node scripts/shot.mjs <path>
node scripts/shot.mjs <path> --dark
```

腳本印出截圖的路徑，頁面會橫向捲動時以失敗結束。要看背景動效的某一刻，加上 `--t <秒數>`。動效本身要在瀏覽器裡看，截圖只有一格。

## 已定的方向與試過的做法

目前的版面是 2026-10-11 定下的基準。以下做法試過後沒有採用，重新提出之前先看這裡：

- 標題直排：標題夾有英文時不易閱讀。
- 系列名放在黑色色塊上：與背景不融合，改為不填色的 `page` 色調。
- 全站一個主色：維持墨色配白紙，加上各系列的色調與固定的琥珀色標記。
- 粉色、圓角、貼紙卡片的柔和風格，以及像素方塊的圖形。
- 遊戲主選單式的首頁：頁面太少，填不滿選單。保留在 `arknights-layout` 分支。
- 背景上跟著滑鼠的選取框：暫時移除。蜂巢格背景保留在 `wallpapers` 分支。
- 掃描線改用綠、青或白色：維持琥珀色。
- 靜態圖捲入視窗時的進場動畫。

另有一條獨立的實驗線在 `anime-scene` 分支：夏日天空的畫布背景配上左、中、右三欄的半透明卡片，沒有合併。

風格上的嘗試在分支上進行，`master` 只放內容與已定案的改動。
